## Deskripsi

Repository ini dibuat untuk memenuhi tugas Pertemuan 1 mata kuliah Pemrograman Berbasis Platform. Tugas ini membahas persiapan lingkungan pengembangan serta analisis perbandingan platform Web, Desktop, dan Mobile.

## Isi Repository

- `README.md` — Informasi repository dan dokumentasi tugas.
- `analisis-platform.md` — Analisis perbandingan platform Web, Desktop, dan Mobile, beserta referensi dan refleksi.

- Git
- Node.js dan NPM

- GitHub

1. Memahami karakteristik platform Web, Desktop, dan Mobile.

3. Menganalisis perbedaan ketiga platform.
